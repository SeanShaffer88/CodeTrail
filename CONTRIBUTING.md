# Contributing

CodeTrail is in planning. Read the product plan, decisions, limitations and project rules before proposing changes. Useful early feedback concerns beginner comprehension, accessibility, curriculum sequencing and feasibility tests.

Use original material. Do not copy course text, exercises, designs or assets without explicit compatible rights and provenance. Keep private data, credentials, machine paths and internal comparisons out of contributions.

Follow confirmed scope and frozen contracts once established. Every implementation slice needs meaningful tests, current docs/corpus evidence and the complete all-target gate. Do not publish placeholder behavior as working functionality. No application build command exists yet.

Original contributions use the repository MIT license. Dependency and asset terms remain separate.
